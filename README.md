# PRG120V-Oblig

A simple web application for registering classes and students. It is made with PHP and MySQL for the course PRG120V (Obligatorisk oppgave 1).

## Content

- `index.html` - Main menu
- `db.php` - Connects to the database
- `registrer_klasse.php`, `vis_klasser.php`, `slett_klasse.php` - register, show and delete classes
- `registrer_student.php`, `vis_studenter.php`, `slett_student.php` - register, show and delete students

## How to use it

1. Open the main menu (`index.html`).
2. Register a class first, since every student must belong to a class.
3. Register students and choose their class from the list.
4. Use "Vis" to see all classes or students, and "Slett" to delete one.
